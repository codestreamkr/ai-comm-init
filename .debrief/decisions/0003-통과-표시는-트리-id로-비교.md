# 0003. 통과 표시는 diff 해시 대신 git 트리 id로 비교

- 날짜: 2026-10-18
- 상태: 채택
- 도메인: gate
- 관련 실행: apply-2, debrief-1
- 영향 문서: skills/ct-debrief/SKILL.md

## 맥락

- 커밋 전에 이해 확인을 통과했는지 판단해야 한다.
- debrief 시점의 내용과 커밋할 내용이 같은지 비교해야 한다.

## 결정

- debrief 때는 새 파일을 포함한 작업 트리 전체를 임시 인덱스로 트리 id로 만든다.
- 커밋 전에는 실제 인덱스의 트리 id와 비교한다. 같을 때만 통과한다.

## 이유

> (질문: 새 파일만 추가한 변경을 git diff HEAD 해시로 판정하면?) 미포함되는 문제

## 버린 대안

- staged diff 해시: 새 파일이 빠지고, 작업 트리 diff와 형식이 달라 비교하기 어렵다.
