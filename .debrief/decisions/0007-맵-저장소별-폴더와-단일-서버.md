# 0007. 맵 데이터는 저장소별 폴더로 나누고 서버 하나가 모든 저장소를 표시

- 날짜: 2026-10-18
- 상태: 채택
- 도메인: map
- 관련 실행: apply-7, debrief-2, debrief-3
- 영향 문서: skills/ct-journal/SKILL.md

## 맥락

- 맵 데이터 폴더를 저장소 이름으로만 구분해서 이름이 같은 저장소의 데이터가 섞였다.
- 맵 서버가 저장소 하나에 묶여 있어 다른 저장소의 흐름이 보이지 않았다.

## 결정

- 맵 데이터 폴더 이름은 `<저장소 이름>-<절대 경로 해시 8자리>`로 한다.
- 맵 서버 하나가 모든 저장소의 맵을 제공한다. 화면은 가장 최근에 갱신된 저장소를 자동으로 따라가고, 저장소를 고를 수 있다.

## 이유

> 고정 포트·재사용, 이름 충돌 방지 — 고정 포트 하나를 쓰고 이미 열린 서버는 다시 열지 않으므로, 떠 있는 서버가 모든 저장소를 보여 줘야 한다. 폴더를 나눈 것은 이름이 같은 저장소가 섞이지 않게 하려는 것이다.

## 버린 대안

- 저장소마다 다른 포트로 서버 실행: 서버 관리가 늘고, 이미 열린 서버를 재사용하는 규칙과 맞지 않는다.
