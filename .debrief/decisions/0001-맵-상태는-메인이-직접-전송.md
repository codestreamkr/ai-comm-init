# 0001. 맵 상태 갱신은 메인 에이전트가 직접 전송

- 날짜: 2026-10-18
- 상태: 채택
- 도메인: map
- 관련 실행: apply-1, debrief-1
- 영향 문서: skills/ct-journal/SKILL.md

## 맥락

- ct 스킬 실행 중 단계 상태를 프로세스 맵에 실시간으로 표시한다.
- 상태 갱신은 한 실행에서 여러 번 일어난다.

## 결정

- 메인 에이전트가 `map.js emit` 명령 한 줄로 이벤트를 보낸다.
- 실행 시작 때 단계 목록을 한 번 보내고, 이후에는 상태 변경만 보낸다.

## 이유

> 토큰은 적게 들어가면서 흐름 및 작업상태를 알 수 있게 하고 싶어.

## 버린 대안

- 저가 모델 서브에이전트가 맵 데이터를 갱신: 호출마다 수천 토큰이 든다.
- 스크립트가 Markdown 기록을 해석해 HTML 생성: 매번 전체를 다시 만들고 실시간성이 낮다.
