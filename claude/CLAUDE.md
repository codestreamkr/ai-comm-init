# 전역 작업 기준

## 응답 언어

- 사용자에게 보이는 모든 응답, 요약, 설명, 계획, 보고는 한글로 작성한다.
- 코드, 식별자, 로그 형식, 명령어, 파일 경로는 원문 그대로 둔다.
- 커밋 메시지와 PR 본문은 해당 저장소의 기존 관례를 따른다.

## 문서 작성

- 문서형 결과물은 맥락에 맞게 간결한 개조식으로 작성한다.
- 문서는 대화를 모르는 사람이 읽는다는 전제로 도달한 결론을 서술한다. 검토, 시도, 논의 등 거기에 이르기까지의 과정은 서술하지 않는다.
- 판단 근거는 관찰된 사실로 적는다. 미확보, 건너뜀, 미검증도 사유와 함께 상태로 적는다.
- 사용자가 별도의 문체나 형식을 지정하면 해당 지시를 우선한다.

### 확인 요청은 답변만 한다

구체적인 지시가 없으면 **답변까지만** 한다.
애매하면 사용자에게 다시 확인하고 진행한다.

## 스킬 파일 위치

- 스킬의 정본은 `~/.agents/skills/<skill-name>/`이다. `~/.claude/skills/`는 여기를 가리키는 심볼릭 링크만 둔다.
- 스킬을 새로 만들거나 수정할 때 `~/.claude/skills/` 아래에 실제 파일을 만들지 않는다.
- 신규 스킬은 `~/.agents/skills/<skill-name>/SKILL.md`로 만들고, 기존 스킬과 같은 구성을 따른다.
- `~/.agents`는 git 저장소다. 스킬을 추가하거나 고친 뒤 추적 상태를 확인하고 사용자에게 알린다.

## 메모리 사용 금지

- 파일 기반 자동 메모리(`~/.claude/projects/*/memory/`)를 사용하지 않는다.
- 메모리 파일을 새로 생성하거나 갱신하지 않고, `MEMORY.md`에도 기록하지 않는다.
- 지속적으로 기억해야 할 기준은 사용자가 직접 이 전역 설정(`~/.claude/CLAUDE.md`) 또는 저장소별 `CLAUDE.md`에 넣는다.
- 기억할 만한 내용을 발견하면 저장하지 말고, 어디에 추가하면 좋을지 사용자에게 제안만 한다.
