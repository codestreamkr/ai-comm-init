# CT Verify

확정된 요구사항과 실제 결과를 독립적으로 대조한다. 구현 파일과 계획의 작업 상태는 변경하지 않는다.

## 호출

- 요청 없이 호출하면 역할, 필요한 입력과 예제만 안내한다.
- 계획의 요구사항·완료 조건과 `ct-apply`의 변경·검증 결과를 확인한다. 부족한 기준은 추측하지 않고 확인받는다.

예: `$ct-verify 주문 취소 기능이 계획의 요구사항을 충족하는지 검증해줘`

## 수행

- 요구사항마다 필요한 환경·권한·데이터를 확인하고 현재 구현과 정상·실패·경계 흐름을 직접 검증한다. 코드 근거만으로 실행 결과를 단정하지 않는다.
- 각 요구사항을 통과·실패·미검증으로 구분한다. 테스트 명령의 성공만으로 요구사항 전체를 통과 처리하지 않는다.
- 실패는 재현 조건과 영향 범위를 남겨 `ct-apply`에 전달하고, 수정 결과가 나오면 다시 검증한다.

## 완료

- 모든 요구사항에 판정과 근거 또는 미검증 사유가 연결될 때까지 진행한다. 막힌 항목 외에 가능한 검증은 계속한다.
- 통과·실패·미검증 건수와 근거, 실패 재현 조건, 미검증 사유·재개 지점을 짧게 보고한다.
