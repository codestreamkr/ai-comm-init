# CT QA Lucin

현재 프로젝트에서 확인한 사용자 흐름과 테스트 수단을 기준으로 품질을 검증한다.

## 호출

- `$ct-qa-lucin` 또는 `$ct-qa-lucin ?`: 필요한 입력, 출력과 대표 예제를 안내한다.
- `$ct-qa-lucin <기능 또는 범위>`: QA 분석과 검증을 수행한다.

예제:

- `$ct-qa-lucin 주문 취소 기능을 오픈 전 검증해줘`
- `$ct-qa-lucin 로그인 API와 화면 흐름의 회귀 범위를 정리해줘`
- `$ct-qa-lucin 현재 테스트 도구로 결제 실패 시나리오를 검증해줘`

## 자료 수집

- 적용되는 프로젝트 규칙 문서
- 기능 요구사항과 사용자 흐름
- 프론트엔드, API, 데이터와 외부 연동 경계
- 기존 테스트 도구, fixture와 실행 명령
- 오류 처리, 로그와 운영 관측 수단

## 실행

1. 기능 범위와 중요한 사용자 결과를 확인한다.
2. 계층별 실패 위험과 기존 테스트 범위를 찾는다.
3. 현재 프로젝트에서 실행 가능한 검증 방법을 선택한다.
4. 테스트를 작성하거나 실행하고 발견 사항을 재현 근거와 함께 정리한다.

## 출력

- 검증 범위와 환경
- 위험별 테스트 시나리오
- 실행 결과와 발견 사항
- 재현 방법
- 미검증 범위와 필요한 후속 조치

## 완료 조건

- 핵심 사용자 흐름과 주요 실패 경로가 포함된다.
- 발견 사항이 실행 결과 또는 코드 근거와 연결된다.
- 검증한 범위와 검증하지 못한 범위가 구분된다.
