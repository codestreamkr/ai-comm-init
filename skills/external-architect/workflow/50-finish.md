# 50-finish

최종 단계에서는 결과를 하나의 문서로 닫는다.

## 반드시 할 일

1. developer 산출물을 반영한다.
2. document 산출물을 반영한다.
3. 리포트, 제안, 실무 구체화를 문서 1개로 통합한다.
4. 공식 문서 미확정 항목을 `확인 필요`로 정리한다.
5. 문서 끝에 `## 이력관리`를 추가한다.

## 필수 산출물

- 최종 문서 파일 1개

## 완료 조건

- developer 산출물이 있다.
- document 산출물이 있다.
- 최종 문서 파일이 실제로 생성돼 있다.
- 최종 문서에 `확인 필요`가 있다.
- 최종 문서 끝에 `## 이력관리`가 있다.

## 역할별 요약

- 호투형: 체크리스트, 리포트, 제안, 위임 결과 검수, 최종 문서 통합
- developer: 개발 가이드 반영 내용 요약
- document: 문서 보완 반영 내용 요약

## 금지

- 위임 결과 없이 문서를 닫지 않는다.
- 최종 문서를 여러 초안으로 남기지 않는다.

## 최종 응답 형식

- 최종 응답에 `역할별 요약`을 포함한다.

1. 문서 위치
2. 반영 범위 요약
3. 확인 필요 또는 남은 위험
