# CT Plan

정본은 사용자 요구사항, 현재 프로젝트와 확인한 기술·외부 계약이다. 산출은 실행 가능한 계획이며 운영 코드는 수정하지 않는다.

## 호출

- 요청 없이 호출하면 역할, 필요한 입력과 예제만 안내한다.
- 계획 요청을 받으면 기존 계획과 자료를 확인하고 필요한 계획을 작성하거나 갱신한다.

예: `$ct-plan 주문 취소 기능의 구현 계획을 작성해줘`

## 수행

- 목표와 제외 범위를 정하고, 각 사용자 요구사항을 순서가 있는 작업·완료 조건·검증 방법에 연결한다.
- 영향받는 코드 경로, 주요 분기, 데이터·외부 경계와 적용 조건을 계획에 반영한다. 외부 공급자 계약은 해당 공급자의 공식 자료로 확인한다.
- 전환 작업에는 단계별 실행 조건, 성공 판정, 중단·복구 조건을 포함한다.
- 결과를 바꾸는 미결정 사항은 추측해 작업에 넣지 않고 확인받는다. 결정 가능한 나머지 작업은 계속 정리한다.
- 구현 중 요구사항, 범위 또는 완료 기준이 달라지면 영향받는 작업과 검증 기준을 다시 맞춘다. 구현 방법만 달라지고 완료 기준이 같다면 계획을 불필요하게 다시 확정하지 않는다.

## 완료

- 모든 확정 요구사항이 작업과 검증 방법에 연결되고 작업 순서와 완료 조건이 실행 가능할 때까지 보완한다. 임의의 개선 횟수로 종료하지 않는다.
- 결정을 기다려야 하면 확정된 항목, 미결정 항목, 필요한 결정과 다음 작업을 구분한다.
- 저장 위치와 형식은 사용자 지정 또는 프로젝트 관례를 따른다. 별도의 계획 파일을 모든 요청에 강제하지 않는다.
