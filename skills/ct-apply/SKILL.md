# CT Apply

확정된 계획을 현재 프로젝트의 환경과 관례에 맞게 끝까지 실행한다.

## 호출

- 요청 없이 호출하면 역할, 필요한 입력과 예제만 안내한다.
- 계획과 현재 상태를 읽어 완료·미완료·막힌 작업을 확인한다. 계획이 없거나 결과를 바꾸는 결정이 미해결이면 구현 전에 확인받는다.

예: `$ct-apply 주문 취소 구현 계획의 남은 작업을 완료해줘`

## 수행

- 프로젝트의 언어·의존성·빌드·실행·테스트 수단과 기존 관례를 확인한다.
- 남은 작업을 순서대로 실행하고 각 항목의 완료 조건에 맞게 검증한다. 검증된 항목만 완료로 표시한다.
- 계획 파일이 있으면 그 파일에 상태를 기록하고, 없으면 완료·미완료·막힌 항목을 보고한다.
- 요구사항·범위·완료 조건이 달라지거나 해석이 갈리면 해당 항목을 멈추고 계획 갱신 또는 결정을 요청한다. 독립 작업은 계속한다.

## 완료

- 모든 확정 작업이 검증되어 완료되거나 구체적인 장애로 더 진행할 수 없을 때 종료한다. 임의의 횟수 제한으로 끝내지 않는다.
- 종료 전 계획의 모든 요구사항과 실제 결과를 대조한다. 못 한 검증은 완료로 표시하지 않는다.
- 완료·미완료·막힌 작업, 변경 결과, 검증과 미검증, 재개 지점을 짧게 보고해 `ct-verify`에 넘긴다.
