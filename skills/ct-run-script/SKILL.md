# CT Run Script

정본은 프로젝트가 실제로 쓰는 명령, 경로, 포트와 환경변수 이름이다.

## 호출

- `$ct-run-script`: 역할, 필요한 입력과 대표 예제를 안내한다. 실행하지 않는다.
- `$ct-run-script <요청>`: 요청한 환경의 실행 스크립트를 만들거나 고친다.

예: `$ct-run-script macOS에서 API와 프론트를 함께 실행하게 해줘`

## 판단

- 대상 OS, 셸과 파일 형식은 사용자 지정, 같은 역할의 기존 스크립트, 프로젝트 관례 순으로 정한다.
- 선택에 따라 실행법이 달라지고 근거가 없을 때만 확인한다.
- 같은 역할의 기존 스크립트가 있으면 새 파일을 늘리지 않고 그것을 갱신한다.
- 기능 코드나 확인되지 않은 설치 절차는 만들지 않는다.

## 완료 기준

- 명령, 경로, 순서와 필요한 외부 서비스가 현재 프로젝트 근거와 일치한다.
- 비밀값은 넣지 않고 환경변수 이름과 필요한 조건만 사용한다.
- 대상 환경에서 쓸 수 있는 방식으로 구문을 검사하고, 현재 환경에서 실행할 수 있으면 실제 시작·종료 흐름을 검증한다.
- 여러 프로세스는 일부 실패, 종료 신호와 남은 프로세스를 처리한다.
- 저장 위치, 실행 방법, 검증 결과와 실행하지 못한 항목의 사유를 보고한다.
