# CT Plan Ext

정본은 프로젝트의 기존 연동과 대상 공급자의 현재 공식 문서다. 산출은 연동·이관 설계이며 코드를 바꾸지 않는다.

## 호출

- `$ct-plan-ext` 또는 `$ct-plan-ext ?`: 안내. 실행하지 않는다.
- `$ct-plan-ext design ?`: `design` 안내.
- `$ct-plan-ext <연동 요청>` 또는 `$ct-plan-ext design <연동 요청>`: `design`으로 실행.

`--`로 시작하면 지원하지 않는 옵션이다. `design`만 있고 요청이 없으면 실행하지 않고 `design` 안내를 한다.

## 작업

- `design`: 유지할 내부 계약과 바꿀 외부 계약을 나눠 목표 구조, 매핑, 이관·검증 순서를 설계한다.
  - 예: `$ct-plan-ext 기존 PG를 새 공급자로 이관`

## 역할 규칙

- 공급자 API·오류·인증은 공식 자료에서 확인한다. 없는 계약을 만들지 않는다.
- 내부 영향과 외부 계약 변경을 섞어 쓰지 않는다.
- 일반 기능 기획·구현 계획은 `ct-plan-work`다.
- 연동 코드 구현은 `ct-code-spring`이다.
