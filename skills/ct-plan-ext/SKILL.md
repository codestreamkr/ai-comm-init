# CT Plan Ext

정본은 프로젝트의 기존 연동과 대상 공급자의 현재 공식 문서다. 산출은 연동·이관 설계이며 운영 코드를 바꾸지 않는다.

## 호출

- `$ct-plan-ext`: 역할, 필요한 입력과 대표 예제를 안내한다. 실행하지 않는다.
- `$ct-plan-ext <요청>`: 요청한 외부 연동 또는 이관 구조를 설계한다.
- Claude Code는 `/ct-plan-ext <요청>`로 호출한다. 호출 뒤 요청이 비어 있으면 안내만 하고 실행하지 않는다.

예: `$ct-plan-ext 기존 PG를 새 공급자로 이관하는 구조를 설계해줘`

## 판단

- 유지할 내부 계약과 바꿀 외부 계약을 분리한다.
- 공급자 API, 인증, 오류와 제한은 최신 공식 자료에서 확인하고 없는 계약을 만들지 않는다.
- 일반 기능 계획은 `ct-plan-work`, 연동 코드 구현은 `ct-code-spring`의 범위로 남긴다.
- 핵심 계약을 확인할 수 없어 설계 결과가 달라지면 추정하지 않고 필요한 자료를 요청한다.

## 완료 기준

- 현재·목표 구조, 인터페이스와 데이터 매핑, 적용되는 오류·재시도·중복 처리와 관측 지점을 포함한다.
- 이관은 데이터 정합성, 단계별 전환, 병행 운영, 중단·복구 조건과 검증 기준을 포함한다.
- 외부 계약 판단에 사용한 공식 문서의 제목 또는 URL, 확인 시점과 적용 버전을 남긴다.
- 내부 영향, 외부 계약 변경, 미확인 사항과 사람의 결정 항목을 구분한다.
