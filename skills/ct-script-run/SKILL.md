# CT Script Run

현재 프로젝트에서 실제로 사용하는 명령과 환경변수를 기준으로 스크립트를 만든다.

## 호출

- `$ct-script-run` 또는 `$ct-script-run ?`: 필요한 입력, 출력과 대표 예제를 안내한다.
- `$ct-script-run <요청>`: 스크립트를 생성하거나 갱신한다.

예제:

- `$ct-script-run macOS 개발 실행 스크립트를 만들어줘`
- `$ct-script-run Windows에서 API와 프론트를 함께 실행하게 해줘`
- `$ct-script-run 현재 Docker 의존성을 포함한 로컬 실행 스크립트를 갱신해줘`

## 자료 수집

- 적용되는 프로젝트 규칙 문서
- 빌드 파일, 패키지 스크립트와 기존 실행 명령
- 서비스 구성, 포트와 실행 순서
- 환경변수 이름과 제공되는 예제 파일
- 기존 Docker 및 운영체제별 스크립트

## 실행

1. 대상 운영체제와 실행 범위를 확인한다.
2. 프로젝트에서 실제 명령과 필수 환경변수를 찾는다.
3. 기존 스크립트 관례에 맞춰 생성하거나 갱신한다.
4. 구문 검사와 안전한 범위의 실행 검증을 수행한다.

## 출력

- 생성하거나 수정한 스크립트
- 필요한 환경변수 이름
- 실행 방법
- 검증 결과와 확인 필요 항목

## 완료 조건

- 명령, 경로와 서비스 순서가 현재 프로젝트와 일치한다.
- 인증값과 비밀값은 스크립트에 포함되지 않는다.
- 대상 운영체제에서 사용할 수 있는 형식으로 검증된다.
