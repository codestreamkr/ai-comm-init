# $wiki-ops prune

`$wiki-ops prune`은 위키 정리 후보를 제안한다.

## 대상

문서가 많아져 정리가 필요할 때 실행한다.

- 중복 개념 정리
- 비슷한 문서 병합 후보 확인
- 오래된 임시 문서 확인
- 색인에 없는 고립 문서 확인

## 절차

삭제하지 않고 후보만 제안한다.

1. `.wiki/index.md`와 실제 문서 목록을 비교한다.
2. 제목, 파일명, 첫 문장이 비슷한 문서를 찾는다.
3. 출처와 이력관리 상태를 확인한다.
4. 병합 후보와 유지 후보를 분리한다.
5. 삭제 후보는 근거와 함께 제안한다.

## 제한

정리 작업은 사용자 확인이 필요하다.

- 문서를 자동 삭제하지 않는다.
- 병합을 자동 수행하지 않는다.
- 출처가 있는 문서는 삭제 후보로 단정하지 않는다.
- `.wiki/raw/` 원문은 정리 대상에서 제외한다.

## 출력

정리 후보를 조치 단위로 쓴다.

- 병합 후보
- 이름 변경 후보
- 색인 추가 후보
- 보관 후보
- 사용자 확인이 필요한 항목
