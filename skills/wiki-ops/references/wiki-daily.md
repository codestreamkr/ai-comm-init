# $wiki-ops daily

`$wiki-ops daily`는 오늘의 위키 작업을 요약한다.

## 대상

하루 단위 현황 확인에 실행한다.

- `$wiki-ops daily`

## 절차

오늘 날짜의 작업만 본다.

1. `wiki/log.md`에서 오늘 날짜 항목을 찾는다.
2. 오늘 생성하거나 수정한 문서를 확인한다.
3. 필요하면 해당 문서를 읽어 핵심 내용을 보강한다.
4. 이어서 처리할 항목을 정리한다.

## 출력

오늘 남긴 지식과 다음 작업을 분리한다.

- 오늘 수집한 원문
- 오늘 생성한 문서
- 오늘 수정한 문서
- 새로 생긴 개념
- 이어서 볼 항목
