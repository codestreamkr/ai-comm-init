# $wiki-ops search

`$wiki-ops search`는 프로젝트 위키를 기준으로 질문에 답한다.

## 대상

사용자가 위키에 쌓인 자료를 기준으로 답변을 원할 때 실행한다.

- 특정 개념 질문
- 특정 인물, 조직, 제품 질문
- 기존 원문 근거 확인
- 관련 문서 탐색

## 호출 예시

명령 다음 텍스트를 질문으로 본다.

- `$wiki-ops search RAG 정리해줘`
- `$wiki-ops search OO회의 언제지?`

## 절차

위키 색인을 먼저 사용한다.

1. `.wiki/index.md`를 읽는다.
2. 질문과 관련된 문서 후보를 찾는다.
3. 관련 문서만 읽는다.
4. 필요하면 `.wiki/log.md`에서 최근 변경을 확인한다.
5. 답변에 사용한 근거 문서를 표시한다.
6. 재사용 가치가 있으면 문서 저장 여부를 사용자에게 확인한다.

## 답변 기준

위키에 있는 내용과 추론을 분리한다.

- 위키 근거가 있는 내용은 근거 문서를 표시한다.
- 근거가 약한 내용은 `확인 필요`로 표시한다.
- 원문에 없는 판단은 `해석`으로 분리한다.
- 새 문서 생성은 사용자 확인 후 수행한다.

## 출력

답변은 짧고 근거 중심으로 쓴다.

- 답변
- 근거 문서
- 확인 필요
- 저장 제안이 필요한 경우 제안
