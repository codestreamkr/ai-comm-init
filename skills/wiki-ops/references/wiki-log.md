# $wiki-ops log

`$wiki-ops log`는 기간별 위키 작업 이력을 요약한다.

## 대상

기간별 정리 요청에 실행한다.

- `$wiki-ops log 1주일간 정리된 내용 알려줘`
- `$wiki-ops log 지난 7일`
- `$wiki-ops log 이번 주`
- `$wiki-ops log YYYY-MM-DD..YYYY-MM-DD`

## 절차

`.wiki/log.md`를 기준으로 정리한다.

1. 요청에서 기간을 해석한다.
2. `.wiki/log.md`를 읽는다.
3. 기간 안의 작업 항목을 추린다.
4. 필요하면 언급된 문서를 읽어 핵심 내용을 보강한다.
5. 남은 확인 필요 항목을 분리한다.

## 기간 기준

상대 기간은 오늘 날짜를 기준으로 계산한다.

- `1주일`, `지난 7일`: 오늘 포함 최근 7일
- `이번 주`: 현재 주의 시작일부터 오늘까지
- 명시 날짜 범위: 사용자가 쓴 날짜를 우선한다.

## 출력

기간별 변화가 바로 보이게 정리한다.

- 기간
- 새로 수집한 원문
- 생성한 문서
- 수정한 문서
- 핵심 정리
- 남은 작업
