# $wiki-ops verify

`$wiki-ops verify`는 특정 위키 문서의 근거와 현재성을 점검한다.

## 대상

문서 품질 확인이 필요할 때 실행한다.

- 특정 문서의 출처 점검
- 원문과 요약 일치 여부 확인
- 오래된 정보 확인
- `확인 필요` 항목 재검토

## 절차

지정 문서와 근거를 대조한다.

1. 사용자가 지정한 문서를 읽는다.
2. 문서의 `## 출처` 또는 링크된 근거 문서를 찾는다.
3. 가능한 원문을 읽어 주요 주장과 대조한다.
4. 출처 없는 핵심 주장을 표시한다.
5. 오래된 정보나 날짜 의존 정보를 표시한다.
6. 수정 요청이 있으면 문서를 갱신한다.

## 점검 항목

검증은 아래 항목만 본다.

- 출처 존재 여부
- 원문과 요약의 일치 여부
- 날짜 의존 정보의 현재성
- 충돌 주장 기록 여부
- `확인 필요` 항목의 적절성
- `## 이력관리` 존재 여부

## 출력

검증 결과는 조치 가능하게 쓴다.

- 문제 없음
- 수정 필요 항목
- 확인 필요 항목
- 수정한 파일
- 직접 확인하지 못한 근거
