# $wiki-ops capture

`$wiki-ops capture`는 원문 자료를 `raw/`에 저장한다.

## 대상

원문으로 보존할 자료를 수집할 때 실행한다.

- URL
- PDF
- Markdown
- 텍스트 메모
- 회의 메모
- 제품 문서
- 외부 문서 발췌

## 저장 위치

자료 유형에 따라 저장 위치를 나눈다.

- 텍스트 원문: `raw/YYYY-MM-DD_slug.md`
- 첨부 파일: `raw/assets/YYYY-MM-DD_slug.ext`
- 여러 출처: 출처별로 파일 분리

## 원문 파일 형식

텍스트 원문은 아래 형식을 사용한다.

```markdown
# 원문 제목

## 메타데이터

- 출처: URL 또는 파일 경로
- 확인일: YYYY-MM-DD
- 수집일: YYYY-MM-DD
- 자료 유형: 웹 문서 / PDF / 메모 / 회의록 / 기타
- 주제: 주제 키워드

## 원문

원문 내용을 둔다.
```

## 기준

원문은 추적 가능해야 한다.

- 가능한 한 원문 전체를 보존한다.
- 임의 요약은 `raw/`가 아니라 `wiki/`에 둔다.
- 출처가 없으면 `출처: 확인 필요`로 표시한다.
- 웹 자료는 URL과 확인일을 남긴다.
- 원문을 수집한 뒤 바로 ingest하지 않는다. 사용자가 요청했거나 자연스러운 다음 단계일 때만 제안한다.

## 출력

수집 결과를 짧게 정리한다.

- 생성한 원문 파일
- 첨부 파일 위치
- 다음 ingest 명령 예시
