# $wiki-ops synthesis

`$wiki-ops synthesis`는 여러 문서를 묶어 종합 문서를 만든다.

## 대상

여러 원문이나 요약이 같은 주제를 다룰 때 실행한다.

- 특정 주제 종합
- 여러 자료의 공통 결론 정리
- 충돌 주장 비교
- 의사결정용 요약

## 절차

근거 문서를 먼저 모은다.

1. `.wiki/index.md`에서 관련 문서를 찾는다.
2. 관련 `.wiki/sources/`, `.wiki/concepts/`, `.wiki/entities/` 문서를 읽는다.
3. 공통 주장과 차이를 분리한다.
4. 충돌 내용은 별도 항목으로 둔다.
5. `.wiki/synthesis/`에 종합 문서를 작성하거나 갱신한다.
6. `.wiki/index.md`와 `.wiki/log.md`를 갱신한다.

## 문서 구성

종합 문서는 판단과 근거를 분리한다.

- 한 줄 결론
- 핵심 내용
- 공통 주장
- 차이점
- 충돌 내용
- 해석
- 확인 필요
- 출처
- 이력관리

## 기준

종합 문서는 원문 요약을 대체하지 않는다.

- 원문별 상세 내용은 `.wiki/sources/`에 남긴다.
- 종합 문서에는 판단에 필요한 내용만 남긴다.
- 출처가 없는 판단은 `해석`에 둔다.

## 출력

종합 결과를 요약한다.

- 생성 또는 수정한 종합 문서
- 사용한 근거 문서
- 충돌 내용
- 확인 필요 항목
