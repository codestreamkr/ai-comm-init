# $wiki-ops lint

`$wiki-ops lint`는 위키 전체 상태를 점검한다.

## 대상

프로젝트 위키의 구조와 문서 품질을 점검할 때 실행한다.

- 색인 정합성 점검
- 출처 누락 확인
- 링크 깨짐 확인
- 중복 문서 후보 확인
- 오래된 주장 확인

## 절차

구조 점검 후 내용 점검을 한다.

1. 허용된 디렉터리 구조가 있는지 확인한다.
2. `wiki/index.md`와 실제 `wiki/` 문서 목록을 비교한다.
3. Markdown 링크가 존재하는지 확인한다.
4. 핵심 주장에 출처가 있는지 확인한다.
5. 제목이나 파일명이 비슷한 중복 문서 후보를 찾는다.
6. 날짜 의존 표현과 오래된 주장 후보를 찾는다.
7. 결과를 문제 목록으로 정리한다.

## 점검 항목

아래 항목을 우선 점검한다.

- 색인 누락 문서
- 깨진 내부 링크
- 출처 없는 핵심 주장
- 중복 개념 문서 후보
- 오래된 주장 후보
- 충돌 기록 누락
- `## 이력관리` 누락
- 허용 구조 밖의 위키 문서

## 자동 수정 기준

자동 수정은 낮은 위험 항목만 수행한다.

- 사용자 요청이 있으면 색인 누락 링크를 추가한다.
- 사용자 요청이 있으면 `## 이력관리` 누락을 보완한다.
- 문서 병합, 삭제, 의미 수정은 사용자 확인 후 수행한다.

## 출력

문제와 조치를 분리한다.

- 심각도
- 파일 경로
- 문제
- 권장 조치
- 자동 수정 가능 여부
