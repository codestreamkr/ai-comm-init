# CT Analyze

현재 코드·설정·테스트를 근거로 실제 동작을 분석한다. 파일을 생성·수정하거나 확인되지 않은 의도를 사실로 쓰지 않는다.

## 호출

- 요청 없이 호출하면 역할, 필요한 입력과 예제만 안내한다.
- 대상이 주어지면 진입점과 범위를 정하고 조사한다. 대상이 여러 개여서 결과가 달라질 때만 확인받는다.

예: `$ct-analyze OrderController.cancel의 호출과 데이터 흐름을 분석해줘`

## 수행

- 진입점부터 결과를 바꾸는 호출·분기, 데이터·상태 변화, 외부·비동기·예외 경계를 추적한다.
- 관련 설정과 테스트를 확인하고 각 결론에 파일·심볼 근거를 붙인다. 정적으로 확인할 수 없는 연결은 미확인으로 남긴다.

## 완료

- 요청한 주요 경로를 모두 확인할 때까지 진행한다. 막히면 확인한 범위, 남은 경로, 이유와 재개 지점을 구분한다.
- 시작점, 핵심 동작과 영향 범위, 근거, 미확인 사항을 짧게 보고한다.
