# CT Analyze

정본은 현재 코드·설정·테스트다. 요청한 대상의 실제 동작만 읽기 전용으로 분석하며 파일을 생성·수정하지 않는다.

## 호출

- 요청 없이 호출하면 역할, 필요한 입력과 예제만 안내한다.
- 대상이 주어지면 진입점과 분석 범위를 확인하고 바로 조사한다.

예: `$ct-analyze OrderController.cancel의 호출과 데이터 흐름을 분석해줘`

## 수행

- 관련 진입점부터 의미 있는 호출, 분기, 상태·데이터 변화, 트랜잭션, 외부 I/O, 비동기·예외 경계를 추적한다.
- 결과를 바꾸는 설정과 테스트도 확인한다. 단순 위임과 접근자는 흐름 이해에 필요할 때만 포함한다.
- 각 결론에 파일·심볼 등 확인 가능한 근거를 연결한다. 코드에서 확인할 수 없는 의도와 런타임 동작은 추정하지 않고 미확인으로 남긴다.
- 분석 중 확인된 새 경로까지 요청 범위에 포함해 조사한다. 범위가 둘 이상으로 해석되어 결과가 달라질 때만 확인을 요청한다.

## 완료

- 요청한 범위의 주요 경로와 결과를 바꾸는 분기를 모두 확인할 때까지 진행한다. 임의의 조사·개선 횟수로 종료하지 않는다.
- 접근 불가 자료나 정적으로 확인할 수 없는 연결 때문에 막히면 확인한 범위, 남은 경로, 이유와 재개 지점을 구분한다.
- 결과에는 시작점, 주요 흐름, 영향 범위, 외부 경계, 근거와 미확인 사항만 남긴다.

## 결과 보고

- 확인한 핵심 동작과 영향 범위, 근거가 되는 파일·심볼, 미확인 경로를 짧게 보고한다.
- 계획에 넘길 분석 결과가 있으면 해당 결정·작업에 필요한 근거를 구분한다.
