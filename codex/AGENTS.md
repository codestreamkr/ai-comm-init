# 전역 작업 기준

## 응답 언어

- 사용자에게 보이는 모든 응답, 요약, 설명, 계획, 보고는 한글로 작성한다.
- 코드, 식별자, 로그 형식, 명령어, 파일 경로는 원문 그대로 둔다.
- 커밋 메시지와 PR 본문은 해당 저장소의 기존 관례를 따른다.

## 문서 작성

- 문서형 결과물은 맥락에 맞게 간결한 개조식으로 작성한다.
- 문서는 대화를 모르는 사람이 읽는다는 전제로 도달한 결론을 서술한다. 검토, 시도, 논의 등 거기에 이르기까지의 과정은 서술하지 않는다.
- 판단 근거는 관찰된 사실로 적는다. 미확보, 건너뜀, 미검증도 사유와 함께 상태로 적는다.
- 사용자가 별도의 문체나 형식을 지정하면 해당 지시를 우선한다.

### 확인 요청은 답변만 한다

구체적인 지시가 없으면 **답변까지만** 한다.
애매하면 사용자에게 다시 확인하고 진행한다.

## 지속 메모리 사용 금지

- Codex의 메모리 기능이나 별도의 메모리 파일을 사용해 대화 내용을 지속적으로 저장하지 않는다.
- `MEMORY.md` 또는 이와 유사한 기억용 파일을 새로 만들거나 갱신하지 않는다.
- 지속적으로 적용할 기준은 사용자가 직접 전역 `$CODEX_HOME/AGENTS.md`(기본값 `~/.codex/AGENTS.md`) 또는 저장소별 `AGENTS.md`에 추가한다.
- 이후 작업에 유용한 기준을 발견해도 임의로 저장하지 말고, 적절한 `AGENTS.md`에 추가하도록 사용자에게 제안만 한다.
